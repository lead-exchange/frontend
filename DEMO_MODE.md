# Демо-режим для локальной разработки

## Обзор

Демо-режим предназначен для локальной разработки и тестирования приложения вне Telegram Mini App. В этом режиме используется специальная авторизация через заголовок `X-Api-Token`.

## Как включить демо-режим

### Команда разработки (рекомендуется)
```bash
npm run start:dev
```
Эта команда автоматически:
- Включает демо-режим
- Добавляет авторизацию через `X-Api-Token`
- Включает eruda консоль для отладки
- Показывает переключатель пользователей

### Обычный запуск
```bash
npm run start
```
Обычный режим без демо-функций для продакшн-тестирования.

## Отличия команд

- **`npm run start:dev`** - режим разработки с демо-авторизацией, eruda, переключателем пользователей
- **`npm run start`** - обычный режим для продакшн-тестирования без демо-функций

## Авторизация в демо-режиме

В демо-режиме вместо стандартной авторизации Telegram Mini App используется заголовок `X-Api-Token` со следующей структурой:

```json
{
  "user": {
    "id": 1,
    "username": "bob"
  },
  "chat": {
    "id": 1
  }
}
```

## Доступные пользователи

### Пользователь Bob (по умолчанию)
- **ID**: 1
- **Username**: bob
- **Chat ID**: 1

### Пользователь Alice
- **ID**: 2
- **Username**: alice  
- **Chat ID**: 2

**Переключение пользователей:** В демо-режиме в правом верхнем углу появляется переключатель для смены пользователя.

## Особенности реализации

1. **Автоматическое определение режима**: `npm run start:dev` автоматически устанавливает `VITE_DEV_MODE=true`
2. **Заголовки авторизации**:
   - В демо-режиме: `X-Api-Token: {...}`
   - В Telegram: `Authorization: tma {...}`
3. **UI компоненты**:
   - Переключатель пользователей появляется только в демо-режиме
   - Eruda консоль включается автоматически для отладки

## Использование в коде

```typescript
// Проверка демо-режима
const isDevMode = import.meta.env.VITE_DEV_MODE === 'true' || WebApp.initDataUnsafe.start_param === 'debug';

// Получение текущего демо-пользователя
import { getCurrentDemoUser } from '@/utils/demoUsers';
const currentUser = getCurrentDemoUser();
```

## Важно

- Демо-режим работает **только** для локальной разработки
- В production сборке эта функциональность отключена
- Все запросы в демо-режиме отправляются на тот же бэкенд, что и в production
- Бэкенд должен поддерживать авторизацию через заголовок `X-Api-Token`
